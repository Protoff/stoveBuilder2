Кликните по кирпичу левой кнопкой.

Памятка по управлению

  • ЛКМ по кирпичу — выделить; тянуть — переставить по сетке
  • ПКМ — вращать камеру, колесо — масштаб
  • ← → ↑ ↓ — вращение камеры
  • C — создать кирпич (дубль кнопки «Создать кирпич»)
  • При перетаскивании: Shift + движение мыши — подъём/спуск по оси Y; колесо — шаг на ряд (65 мм)
  • X — поворот вокруг оси X на 90°
  • Y или R — поворот вокруг оси Y на 90°
  • Z — поворот вокруг оси Z на 90°
  • PageUp / PageDown — поднять/опустить выделенный кирпич на ряд
  • Delete / Backspace — удалить выделенный кирпич
  • Esc — снять выделение
Новый кирпич появляется рядом с существующими, не перекрывая их. При отпускании мыши кирпич встаёт на сетку 62.5 мм (края — точно на линии) и примагничивается к соседям: встык, выравнивание граней, постановка сверху. Высота ряда — строго 65 мм, кирпичи не врезаются друг в друга. Клик по пустому месту снимает выделение.
